## Known inconsistencies in the source itself

The Conservatory's own pages disagree on the pipe count:

- `concert-organ`: "approximately 12,700 individual pipes"
- `donations`: "more than 12,700 individual pipes"
- `buyapipe`: "more than 12,800 individual pipes"

This site uses **more than 12,700**, the figure two of the three pages give.
